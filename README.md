# מחשבון הדפסה A1 – אפליקציית אנדרואיד

אפליקציה שמחשבת מחיר להדפסת חלק ב-PLA או PETG במדפסת Bambu Lab A1. עובדת בלי אינטרנט, וההגדרות נשמרות בטלפון.

## בניית ה-APK דרך GitHub (בלי להתקין כלום במחשב)

1. צור ריפו חדש ב-GitHub (למשל `PrintCalc`).
2. העלה אליו את כל התוכן של התיקייה הזו, כולל התיקייה `.github` (אפשר דרך "Add file" ← "Upload files", או עם git).
3. היכנס ללשונית **Actions**. הבנייה מתחילה לבד אחרי העלאה ל-`main`, או שאפשר להריץ ידנית עם **Run workflow**.
4. כשהריצה מסתיימת (סימן ירוק, בערך 3–5 דקות), פתח אותה והורד את **PrintCalc-apk** בתחתית העמוד.
5. חלץ את ה-ZIP, העבר את `app-debug.apk` לטלפון והתקן. צריך לאשר התקנה ממקורות לא ידועים.

## בנייה מקומית ב-Android Studio

פתח את התיקייה ב-Android Studio ← Build ← Build APK(s).

## שינוי המחשבון

כל הממשק והחישוב נמצאים בקובץ אחד: `app/src/main/assets/index.html`.
